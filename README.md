# Masteroppgave

Dette er masteroppgaven jeg skrev i samfunnssikkerhetsprogrammet på Aarhus Universitet, som jeg leverte i septermber 2025.

Den er skrevet som et Quarto-prosjekt, og jeg brukte anledningen til å lære meg tekstanalyse i R, med `stm`-pakka der.

Etter at jeg leverte den inn har jeg fortsatt å jobbe litt med den, med mål om å gjøre funnene mine litt mer tilgjengelige.

# Masteroppgave

Dette er masteroppgaven jeg skrev i samfunnssikkerhetsprogrammet på Aarhus Universitet, som jeg leverte i septermber 2025.

Den er skrevet som et Quarto-prosjekt, og jeg brukte anledningen til å lære meg tekstanalyse i R, med `stm`-pakka der.

Etter at jeg leverte den inn har jeg fortsatt å jobbe litt med den.

Planen for videreutviklinga er som følger:

- Bytte ut main.R med en taskfile, sånn at prosjektet kan kjøres med `task`
- Bytte ut Github Actions workflowene med det samme
- Oppdatere koden til å være mer lesbar, raskere og ha færre avhengigheter
- Gå gjennom Git historikken og fjerne de store unødvendige filene, slå sammen dårlige commiter, og generelt lage en litt mer forståelig fremgangsmåte

Så til slutt skal jeg vurdere om ikke jeg skal prøve å skrive om oppgaven, eller skrive om koden, til at den kan genereres inline i teksten istedenfor.
